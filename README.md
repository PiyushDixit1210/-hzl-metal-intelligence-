# HZL Metal Intelligence

Interactive application prototype built from the supplied meeting requirements summary. Open `dist/index.html` or serve `dist` with any static web server. No build or dependencies required. No live integrations, trained forecasting model or customer-data transfer is included.

## Included

Seven integrated views: overview; monthly order-book scenarios; import/shipment radar; import-parity and auction premium workbench; editable customer demand and share of wallet; country screening and allocation; sources, onboarding and phased implementation.

Select zinc/lead and rolling three-month/next-quarter horizons. Change scenario inputs, edit or add sample customers, adjust pricing and allocation, export the selected view, or download the implementation brief. Browser changes persist in local storage. Reset from Data & implementation.

## Evidence and limitations

The only source is the user's pasted requirements summary. All numeric records and coefficients are synthetic. No market fact or investment recommendation is inferred from them. Above-90% confidence is a client preference requiring a precise metric and empirical validation. Sensitivity bands are not confidence intervals. Source release timing and licenses need verification. The previous vendor name and exact reason it ceased to be useful were absent from the summary and remain open.

## Production requirements

Connect licensed trade, shipment, market and customer sources; implement authenticated APIs, server-side persistence, customer access controls and auditing. Establish historical snapshots, reproducible forecasting/backtests and calibrated intervals before presenting predictive performance. Validate HZL pricing formulas, duties, Incoterms and freight treatment. Confirm commercial onboarding and relevant PO arrangements before third-party customer-data access.

See the in-app implementation brief for candidate schemas, model inputs and phased delivery.
